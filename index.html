Aplikasi SI AWK menggunakan arsitektur gas-pro-api. Anda dapat menghubungkan WebApp frontend ini ke backend Google Apps Script Anda.

Biarkan kosong jika ingin menggunakan mode simulasi lokal/demo berkecepatan 0ms.

Panduan Deploy GAS:

1. Buka file backend/Kode.gs di editor Google Apps Script.

2. Jalankan fungsi setupAppEnvironment() sekali untuk auto-generate Spreadsheet & Drive.

3. Klik Deploy → New deployment (Pilih: Web App, Execute as: Me, Who has access: Anyone).

4. Salin URL Web App dan tempelkan di kotak di atas.
